# 展览导览：内容发布闭环

一个把「草稿编辑」与「已发布内容」严格分离的展览导览原型。编辑永远只改草稿；
访客页与二维码永远解析**最近一次发布快照**；发布之后继续修改草稿，不会改变已经
分享出去的链接和二维码。

## 发布闭环规则

1. **草稿 / 发布分离**
   - 编辑区修改（标题、展厅、介绍、音频、勾选发布）只写入工作副本。
   - 点「发布更新」会生成一条**不可变快照**（版本号、时间、内容哈希、展项清单），
     访客页 `#/visitor` 只读取最后一条快照。
2. **发布闸门**（发布前必须满足，否则弹窗阻止并说明原因）
   - 下一次发布中必须至少有一个展项——空发布（包括「把线上展项全部撤回」）会被阻止；
   - 选中内容与最新快照完全一致时阻止（没有需要发布的更改）。
3. **短码**
   - 展项**首次被发布**时自动分配短码（去易混字符的 31 进制，计数器编码），
     历史快照与草稿中的短码共同构成「已用集合」，**永不复用给其他展项**。
   - 撤回后该短码不再出现在最新快照：访客扫码看到「已撤回」页（短码失效），
     页面提供最后包含它的历史快照入口用于核对；编辑侧显示「已撤回」。
   - 同一展项重新发布时**恢复其原短码**，不会新分配。
4. **历史快照可核对**：发布记录里的每个版本都有独立链接 `#/v/:version`，
   快照详情 `#/v/:version/c/:code` 固定展示当时内容，并带「历史快照」横幅。
5. **一致性**：所有状态持久化在 localStorage；hash 路由让刷新、编辑/访客预览切换、
   多标签页（storage 事件）后草稿、发布状态、访客解析结果保持一致。

## 路由

| 路径 | 含义 |
| --- | --- |
| `#/edit` | 编辑工作台（默认） |
| `#/visitor` | 访客页 = 最新发布快照 |
| `#/v/:n` | 第 n 次发布快照（核对用，带历史横幅） |
| `#/c/:code` | 二维码入口：解析短码（在线 / 已撤回 / 未知） |
| `#/v/:n/c/:code` | 某条历史快照中的展项详情 |

## 命令

```bash
npm install
npm run dev       # 开发服务器
npm test          # 33 个测试：模型规则 + SSR 渲染 + jsdom 交互集成
npm run build     # 生产构建
```

## 代码结构

```
src/
  model/store.js          框架无关的核心模型（纯函数，含全部发布规则与持久化）
  router.jsx              hash 路由解析
  App.jsx                 状态 / 持久化 / 跨标签同步 / 路由分发
  components/
    Workbench.jsx         编辑工作台：草稿、勾选发布、发布确认弹窗、发布记录
    Visitor.jsx           访客列表 / 快照列表 / 短码解析（在线·撤回·未知）
    QR.jsx                真实可扫描二维码（qrcode 生成 data URL）
test/
  store.test.js           发布规则单元测试
  flow.test.js            端到端状态流转
  render.test.jsx         组件 SSR 冒烟
  integration.test.jsx    jsdom 真实交互（点击发布、撤回、路由切换、刷新重载）
```
